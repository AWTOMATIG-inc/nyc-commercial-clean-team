## What was completed

### Item 1: Leftover template line
- Removed "Cleaning Driving And Security Service" from `src/components/quote/ProfessionalCareServices.jsx`. The section now reads: "Insured, trained crews delivering reliable commercial cleaning across all five NYC boroughs." It shows on every CMS page.
- **Facility Type dropdown: no bug.** Tested on a phone and in Chrome DevTools, on a service page and on `/booking`. It opens, selects, validates and submits. The scanner most likely could not read the custom (non-`<select>`) dropdown. No code change.

### Item 3: Canonical tags and share links
- New helper `src/utility/pageMeta.js` builds the canonical URL and a per-page `og:url`, title and description.
- Applied to 7 pages: Home, About, Services, Locations, Contact, Booking, and the Blogs listing.
- Checked in the built HTML: each page's canonical and `og:url` are its own URL, not the homepage.
- The homepage description no longer shows `&amp;`, and the missing space in "more.Serving" is fixed.
- Titles and descriptions on those pages were **not rewritten**. Those drafts belong to marketing.

### Item 5: Cache
- No code change. The deploy script runs `rm -rf .next`, then `npm run build`, then `pm2 restart`. That clears Next.js's cache on every deploy.
- The old pages the reviewer saw were most likely cached by browsers (they cache 308 redirects hard) or by Google's index.

### Item 6: One H1 per page
- `/industries/*` pages and `/service-area/foundation/*` pages had no H1, because the heading was an `<h4>`. Both are now `<h1>`.
- About already has a single H1. The Counter fix from the first fix pack resolved it, so the "about 13" in the doc was out of date.

### Item 8: Business name, address, phone
- **One business name, matched to Google.** See the next section.
- **Phone links.** Every call button now uses `tel:+16313817252`. The old links had spaces and parentheses. The Booking page's "Prefer to Talk?" box was worse: it built `tel:tel:+1 (631)…` and `mailto:mailto:…`, so the call and email buttons were likely broken on phones. Fixed.
- **"Suite 1"** added to the Contact page address card and the map popup. The chatbot reads the same constant, so it now says Suite 1 too.

### Extras found while working
- **Opening hours.** The Contact page says "Open 24 Hours, 7 Days a Week", but the homepage schema said Mo-Fr 08:00-18:00. The schema now says 24/7: all seven days, 00:00 to 23:59. Google's Rich Results Test shows these fields.
- **Rating text.** The quote form said "4.9 rated by 200+ NYC facility managers" and the reviews block said "based on 200+ reviews". The Google listing shows **4.9 with 55 reviews**. Both now match the listing ("4.9 rating on Google (55 reviews)" and "4.9 out of 5 — based on 55 Google reviews"). The 55 is hard-coded, so update it in `QuoteForm.jsx` and `ManagerReview.jsx` as the review count grows.
- **Schema name.** Added the missing period, so it reads "New York Commercial Clean Team Inc.".
